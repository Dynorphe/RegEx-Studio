# RegEx Studio 交互与视觉体验优化方案

针对您提出的 4 项改进点与确认偏好，我们将对正则表达式编辑器、匹配结果分组着色、底部表格折叠与列宽拖拽以及界面文案进行全面升级。

## User Review & Critical Decisions

> [!IMPORTANT]
> 以下为本次迭代确认的 4 项核心优化内容，确认后我们将立即更新代码：

- **确认优化 1 — Pattern 输入框多彩括号高亮（与下方分组颜色联动）**：
  - 采用双层同步渲染技术（透明光标输入层 + 实时语法高亮底层），为每个捕获分组 `(...)`、`(?<name>...)`、`(?'name'...)` 的左/右括号及命名标签分配专属高辨识度色彩（琥珀、翠绿、紫罗兰、玫瑰、青色、靛蓝循环），并与下方匹配结果预览中的分组高亮颜色保持 **1:1 严格对应**；同时支持光标靠近括号时的配对括号高亮提示。
- **确认优化 2 — 匹配结果按分组逐段高亮 + 悬停气泡显示分组标签**：
  - 彻底移除匹配文本最开头生硬的 `#1 (?<date>)` 前置胶囊标签，保证匹配结果与原测试文本的字符流排版完全一致。
  - 当匹配中存在捕获分组时，按每个子分组的实际起止区间（`startIndex` ~ `endIndex`）对各个分组文本片段分别添加对应的分组专属高亮色与底边线。
  - 当鼠标悬停在任意分组高亮片段（或全文匹配片段）上时，实时弹出轻巧的浮动气泡（Tooltip），展示对应的 **`.NET` 分组标签与组名**（如 `(?<date>)`、`(?'time')`）、所属 `Match #`、`Index`、`Length` 与完整捕获内容。
- **确认优化 3 — 底部列表多层折叠 + 表头列宽自由拖拽**：
  - **面板与行级双重折叠**：既支持一键收起/展开整个底部面板，也支持在表格中点击每个 `Match #` 行展开或折叠其子分组，并提供 **「全部展开 / 全部折叠」** 按钮。
  - **可拖拽列宽（Resizable Table Columns）**：表头每一列右侧提供列宽拖拽分隔线，按住鼠标左右拖动即可自由调整各列宽度。
- **确认优化 4 — 提示文案全面精简**：
  - 移除所有类似“1. 正则表达式”、“2. 上栏：测试文本输入区”、“3. 下栏：匹配结果实时高亮预览”、“实时匹配工作区 (上下双栏比对)”等冗余方位描述，统一精简为自然简洁的标题（**`正则表达式`**、**`测试文本`**、**`匹配结果`**、**`捕获分组`**、**`替换测试`**）。

## 1. Overview & Core Concept

- **What It Does**：让正则表达式中的每一个分组括号、匹配文本中的每一个被捕获片段、以及详情表中的每一行数据通过**统一的色彩编码与悬停交互**无缝贯通，同时保持测试文本与匹配结果的纯净对齐。
- **Key Value**：消除前置标签对长文本字符对齐的干扰，让多分组正则（如复杂日志、身份证、URL 解析）的分组边界一目了然。

---

## 2. User Experience & Visual Design

- **Key User Flows**：
  1. **Pattern 括号染色与配对检视**：在 `正则表达式` 输入框中编写表达式时，左括号 `(`、分组名 `(?<name>` / `(?'name'` 及配对的右括号 `)` 自动呈现该分组的专属色彩；若括号未闭合，未配对括号以醒目红色标注。
  2. **纯净分组高亮与悬停气泡**：在 `匹配结果` 区域，全文匹配以柔和浅底色铺底，内部的各个捕获分组以各自的专属色彩高亮；鼠标移入某一段分组文本时，上方立即浮现气泡显示 `(?<date>) · Group #1 | Index: 1, Length: 10`。
  3. **可折叠与可调宽的分组表格**：在底部 `捕获分组` 表中，点击 `Match #1` 即可折叠或展开其子分组，或使用顶部「全部折叠」仅看全文匹配概览；拖动表头分隔线可随时拉宽“分组名称”或“捕获内容”列。
- **Visual Identity & Group Color System**：
  - **Full Match ($0)**：柔和浅蓝底色（`bg-blue-500/10`）配细虚线底边，不喧宾夺主。
  - **Group Palette（Pattern 括号与匹配片段共享）**：
    - Group 1：Amber（琥珀金）
    - Group 2：Emerald（翠绿）
    - Group 3：Violet（紫罗兰）
    - Group 4：Rose（玫瑰红）
    - Group 5：Cyan（青蓝）
    - Group 6：Orange（暖橙）
